Painel Admin Schema-Driven & Live Preview

Evolução do site Vila Chico Bento para um motor reutilizável de sites institucionais com admin desacoplado.

🛡️ Decisões Travadas (Locks)
  • ✔
    Módulo Local no Piloto: Implementar a pasta lib/modules/admin direto dentro do vila-chico-bento-site, mantendo o nano_core intacto e agnóstico.
  • ✔
    Arquitetura Schema-Driven: O Admin é agnóstico ao layout visual. Ele lê um catálogo de campos declarativos (AdminField.text, AdminField.image, AdminField.gallery) e gera o formulário automaticamente. O layout consome dados por chave e tem fallback para valores locais caso o banco falhe.
  • ✔
    UX de Live Preview: Split-screen (Desktop) com formulário à esquerda e preview em tempo real à direita, além de controle de rascunho com botão de publicar.
  • ✔
    Multi-tenant Seguro no Firebase: Gerenciado na conta da agência via Firestore (sites/{siteId}) com Security Rules estritas para que nenhum cliente veja dados alheios. Cliente final nunca toca no Google Cloud Console.
  • ✔
    Exportação para Skill: Após validação com a Vila Chico Bento, o padrão será exportado como Skill no repositório nano-agents para automação de novos sites.
  • ✔
    Governança por Epics & Stories: Fluxo completo de documentação formal para garantir rastreabilidade de entrega.
🛑 Opções Rejeitadas (Killed)
  • ✖
    Package Dart Separado Imediato: Rejeitado para evitar sobrecarga de múltiplos repositórios, versionamento precoce e burocracia de pubspec antes de testar em produção.
  • ✖
    Editor de Layout Livre (Estilo Wix): Rejeitado. O cliente só edita textos e fotos; o design e responsividade permanecem 100% sob controle do desenvolvedor.
  • ✖
    Console Firebase nas Mãos do Cliente: Rejeitado devido ao risco de perda de senhas, custos acidentais e exclusão indevida de dados.
