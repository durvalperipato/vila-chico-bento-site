- (direction) Idea: Painel admin em Flutter Web (Nano Core) para editar textos do Hero, cards de seções e upload de até 10 fotos para a galeria com preview/teste
- (crack) Dilema do cliente: A dona da creche perguntou se ela mesma poderia alterar textos da Landing Page. Decisão de modelo de negócio: Painel admin customizado vs. Contrato de suporte/mensalidade de manutenção
- (direction) Objetivo real revelado: Vila Chico Bento é laboratório/piloto de um template 'Core' reutilizável para criar e vender sites institucionais mais rápido para futuros clientes, onde o painel admin é um ativo de produto/diferencial de venda.
- (crack) Risco identificado: Cliente final não entende de Firebase e não pode ter acesso ao console da GCP/Firebase sob hipótese alguma. Risco de corrupção de dados ou perda de credenciais.
- (crack) Escalabilidade multi-tenant: 50 sites em um único Firebase é perigoso? Como funciona o mapeamento de domínios customizados (ex: vilachicobento.com.br) para múltiplos sites?
- (crack) Estrutura heterogênea entre sites: O site do Zé pode ter seções e estruturas diferentes do Chico Bento. Como criar um Admin / Core que suporte layouts e seções dinâmicas sem virar um WordPress/Wix complexo demais?
- (crack) Nível de granularidade do Admin: O usuário quer saber se o Admin deve controlar variações de layout/design do Hero (ex: com/sem foto, 5 textos vs 1 título alinhado à esquerda, foto de fundo).
- (crack) Desafio de desacoplamento: Como plugar o Admin em um site 100% customizado (layout fornecido pelo cliente no Figma que muda tudo) sem precisar reescrever o Admin a cada projeto?
- (lock) Arquitetura Aprovada: Schema-Driven Admin (Admin Orientado a Esquema) com Split-Screen Preview em tempo real. O Admin é desacoplado e lê um catálogo de campos declarativos (AdminField.text, AdminField.image, AdminField.gallery).
- (crack) Dúvida conceitual: O que seria esse 'nano-cms' e precisa mesmo ser um package Dart? Esclarecer a diferença prática entre ter um package no pub.dev/git vs simplesmente ter o módulo de admin dentro dos sites.
- (lock) Fluxo de Execução Travado: 1) Implementar e validar o módulo 'admin' dentro do vila-chico-bento-site; 2) Exportar a automação para uma skill no nano-agents. O usuário requisitou formalmente a esteira completa com Epics e Stories para deixar tudo documentado.
