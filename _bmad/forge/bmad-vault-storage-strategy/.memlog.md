- (assumption) Proposta: Mover dados do _bmad para nano-devs-vault/bmad/{projeto} e conectar via symlink com _bmad/ no .gitignore do projeto para manter o GitHub limpo.
- (crack) Dessincronizacao de Branches: O vault nao acompanha os checkouts de branches do projeto de codigo, quebrando o versionamento conjunto de specs e diffs.
- (crack) Fragilidade de Symlinks entre maquinas: Symlinks exigem caminhos relativos identicos e .gitignore impede sincronizar estado do BMad ao clonar em novo ambiente.
- (kill) Descartado symlink externo para nano-devs-vault: a complexidade de manter dois repositorios e branches sincronizadas supera qualquer ganho estatico de limpeza.
- (decision) Decidido manter o _bmad/ dentro do projeto para preservar atomicidade do Git e portabilidade multi-maquina. Remocao pontual so ocorrera em caso de handoff para cliente.
